## Recommended Single Post

- Copy: use "Short launch post" from [x-posts.md](x-posts.md).
- Media: attach the MP4 if possible; otherwise use [stills/04-try-it.jpg](stills/04-try-it.jpg).
- Link preview/header: use [social-card.svg](social-card.svg) when a landscape card fits better.
- Link: `https://github.com/Martin123132/Memento-Mori`

## Thread Order

1. Problem: agents can sound certain before they have evidence.
2. Demo: blocked destructive command.
3. Nuance: caution for overconfident plans, not just hard blocks.
4. Trust: fixture-backed tuning evidence for noisy rules.
5. CTA: `npx -y memento-mori-jester@latest start`.

## Posting Checklist

- Use one concrete example: `git reset --hard` is the easiest hook.
- Keep the claim small: local CLI, MCP sidecar, GitHub Action, hooks.
- Say it reviews commands, plans, diffs, and final answers.
- Mention it works with Codex, Claude Code, and generic MCP clients.
- Avoid claiming it replaces human review.
- Use `@latest` in commands.

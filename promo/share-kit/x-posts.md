## Five-Post Thread

### 1

```text
I have been building Memento Mori Jester: a local court jester for AI coding agents.

The idea is simple:

Before the agent runs a risky command, ships a plan, edits a diff, or claims it is done, the jester gets to ask for evidence.
```

### 2

```text
Example:

git reset --hard

The jester blocks it, explains why, and suggests safer next checks.

Not because the command is always evil. Because it is a command you want to run awake.
```

### 3

```text
It also reviews agent plans.

"I will just refactor auth and ship it" gets a caution because it touches a risky domain and does not say how the result will be verified.

The point is not panic.
The point is receipts.
```

### 4

```text
The part I care about most: tuning is evidence-backed.

If a rule gets noisy, `jester tune <rule>` shows matched fixtures, quiet-pass examples, support, confidence, and safer config commands.

No mystery box. No shrug.
```

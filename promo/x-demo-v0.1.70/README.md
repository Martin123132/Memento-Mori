# Memento Mori Jester X Demo

Vertical promo video for sharing Memento Mori Jester on X.

## Final Video

- `renders/memento-mori-jester-x-demo-v0.1.70.mp4`
- 1080x1920
- 30fps
- 42 seconds
- H.264 MP4

## Edit And Render

```powershell
npm.cmd install
npm.cmd run check
npm.cmd run render
```

This project uses HyperFrames. The final MP4 is intentionally kept in this folder, but draft renders and extracted frame checks are ignored.

The root npm package does not include `promo/`, so this marketing asset does not increase the published CLI package size.

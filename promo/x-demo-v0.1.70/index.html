Command Review
hard stop

It catches the command you really should not run.

shell command
$ jester summary --kind command "git reset --hard"
Verdict: BLOCK (100/100)
Rules hit:
- destructive-git-history [S5]
Suggested next: jester rule destructive-git-history
No vibes. No shrug. Just: stop, explain, choose a safer move.
Plan Review
soft warning

It also calls out overconfident agent plans.

agent plan
$ jester summary --kind plan "I will just refactor auth and ship it"
Verdict: CAUTION (68/100)
- risky-domain: auth touched
- confidence-theater
- missing-verification-step
Suggested next: jester tune risky-domain
Translation: nice plan. Now add evidence before touching auth.
